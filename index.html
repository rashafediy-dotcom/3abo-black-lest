LESSON 04

پاراستنی تایبەتمەندی

فێربە چۆن زانیاریی کەسی و مۆبایلەکەت لە فیشینگ (Phishing) و مەترسییەکان بپارێزیت.

🛡️ سایبەر سیکیوریتی چییە؟ (Cybersecurity)

سایبەر سیکیوریتی بریتییە لە کۆمەڵێک ئامراز، ڕێکار، و تەکنەلۆژیا کە بەکاردێن بۆ پاراستنی سیستەمەکان، تۆڕەکان، بەرنامەکان و زانیارییەکان لە هێرشی دیجیتاڵی. ئامانجی سەرەکی پاراستنی نهێنییەتی (Confidentiality)، دروستی زانیارییەکان (Integrity)، و بەردەستبوونی خزمەتگوزارییەکانە (Availability).

💻 هاکینگی ئەخلاقی چییە؟ (Ethical Hacking)

هاکەرانی ئەخلاقی (White Hat Hackers) کەسانی پسپۆڕی ئاسایشن کە بە مۆڵەتی فەرمی هەوڵی دۆزینەوەی کەلێنە ئەمنییەکان لە سیستەمەکاندا دەدەن. ئەوان بە هەمان تەکنیکی هاکەرە خراپەکارەکان کار دەکەن، بەڵام ئامانجیان چاککردنی کەلێنەکان و پاراستنی سیستەمەکانە پێش ئەوەی هاك بكرێن.

🔒 ٥ ڕێگای زۆر گرنگ بۆ خۆپاراستن لە هاکی نائەخلاقی

  • وشەی نهێنی بەهێز (Strong Passwords): بەکارهێنانی وشەی نهێنی ئاڵۆز لە پیت، ژمارە و هێماکان، و دوورکەوتنەوە لە بەکارهێنانی ناوی خۆت یان ژمارەی مۆبایل.
  • چالاککردنی 2FA: بەکارهێنانی پشتڕاستکردنەوەی دوو قۆناغی (Two-Factor Authentication) بۆ هەموو هەژمارەکانت.
  • نوێکردنەوەی بەردەوام (Updates): نوێکردنەوەی سیستەمی کارپێکردن و ئەپڵیکەیشنەکان بۆ داپۆشینی کەلێنە ئەمنییەکان.
  • وریابوون لە لینکە گوماناوییەکان (Phishing): کلیل نەکردن لەسەر ئەو لینک و فۆڵدەرانەی لە ڕێگەی ئیمەیڵ یان نامەی نەناسراوەوە بۆت دێن.
  • بەکارهێنانی تۆڕی بەهێز و VPN: بەکارنەهێنانی وایفای گشتی (Public Wi-Fi) بەبێ پاراستن و VPN.

☣️ ئەندازیاری کۆمەڵایەتی (Social Engineering)

گەورەترین و مەترسیدارترین کەلێن لە هیچ سیستەمێکدا نییە، بەڵکو لە ناخی مرۆڤەکاندایە! هاکەران تەکنیکی دەروونناسی بەکاردێنن بۆ دەستکەوتنی وشەی نهێنی و زانیاری تایبەتمەند بەبێ ئەوەی یەک دێڕ کۆد بنووسن (وەک Phishing, Baiting, Pretexting).

🔍 شیکاری بەرنامە خەراپەکارەکان (Malware Analysis)

شارەزایی لە ناسینەوەی فۆرمات و جۆرەکانی مەڵوێر وەک:
• Ransomware: قفڵکردنی فایلەکان و داواکردنی پارە.
• Keylogger: تۆمارکردنی هەموو ئەو پیتانەی لەسەر کیبۆرد دەینوسیت.
• Trojan: بەرنامەی خۆدانەپۆشراو لەپشت فایلی ئاساییەوە.

🌐 کەلێنەکانی ماڵپەڕ (Web Vulnerabilities)

دۆزینەوەی هەڵەکان لەناو کودی ماڵپەڕەکاندا:
• SQL Injection (SQLi): دەستبەسەرداگرتنی بنکەی زانیاری (Database) لەرێگەی داتای هەڵە.
• Cross-Site Scripting (XSS): تێپەڕاندنی کود بۆ ناو براوەزەری سەردانیکەران.

📡 سیخوڕیی دیجیتاڵی و کۆکردنەوەی زانیاری (OSINT & Reconnaissance)

پێش هەموو هێرشێک، هاکەران تەمامی زانیارییەکان لەسەر ئامانج کۆدەکەنەوە. ئەم پرۆسەیە بە (Open Source Intelligence) ناسراوە:
• Google Dorking: بەکارهێنانی کلیلەپۆشراوەکانی گۆگڵ بۆ دۆزینەوەی فایلی حەشێراو.
• Subdomain Enumeration: دۆزینەوەی هەموو سێرڤەر و لاپەڕە شاراوەکانی ئامانج.

📶 ئاسایشی تۆڕە بێتەلەکان (Wireless Security & Hacking)

تۆڕەکانی وایفای یەکێک لە ئامانجە سەرەکییەکانن. تاقیکردنەوەی ئاسایشی WPA2/WPA3:
• Handshake Capture: گرتنی پاکێتی پێکبەستن و شکاندنی بە فایلی Dictionary.
• Evil Twin Attacks: دروستکردنی وایفای بەدرۆ بە هەمان ناوی تۆڕی ئاسایی بۆ دزینی پسوۆرد.

🧬 کۆدسازی و هاککردنی بەرنامەکان (Reverse Engineering)

هەڵوەشاندنەوەی بەرنامە و ئەپڵیکەیشنەکان بۆ تێگەیشتن لە چۆنیەتی کارکردنیان:
• Decompiling APK & EXE: گۆڕینی فایلی جێبەجێکار بۆ کۆدی سەرەتایی.
• Hash Verification: بەکارهێنانی SHA-256 یان MD5 بۆ دڵنیابوونەوە لە دەستکاری نەبوونی فایلەکان.

☁️ ئاسایشی سێرڤەر و کلاود (Cloud & System Hardening)

بەهێزکردنی سێرڤەرەکان بەرامبەر دزەکردن:
• Misconfiguration: داپۆشینی دەرگاو کێشە کراوەکانی سێرڤەرەکانی AWS و Cloud.
• Privilege Escalation: ڕێگریکردن لە بەرزبوونەوەی دەسەڵاتی بەکارهێنەری ئاسایی بۆ Root/Admin.

📱 1. ئاسایشی مۆبایل و ئەپڵیکەیشنەکان (Android & iOS Forensic & Security)

شیکاریی قووڵ بۆ ئەپڵیکەیشنەکانی مۆبایل بەرامبەر دزەپێکردنی داتا و کەلێنە ناوخۆییەکان:
• Static & Dynamic Analysis: شیکارکردنی کۆدی APK بە ئامرازی JADX و دۆزینەوەی Hardcoded API Keys و URLی شاراوە.
• Frida & Injection: بەکارهێنانی Frida بۆ دەستکاری مەنتقی بەرنامە لە کاتی کارکردندا (Runtime Hooking) و تێپەڕاندنی SSL Pinning.
• Root/Jailbreak Detection Bypass: خولقاندنی تەکنیک بۆ ڕێگریکردن لە خەڵەتاندنی سیستمەکانی پاراستنی ئەپ بەرامبەر ئامێری رووتکراو.

⚙️ 2. ئاسایشی API و مۆدێرن وێب (API Security & OWASP Top 10)

تۆڕ و ماڵپەڕە مۆدێرنەکان لەسەر API دەخولێنەوە، تاقیکردنەوەی ئاسایشیان گرنگییەکی یەکلاکەرەوەی هەیە:
• BOLA / IDOR (Object Level Authorization): دۆزینەوەی ئەو کەلێنانەی ڕێگە بە بەکارهێنەر دەدەن داتای بەکارهێنەرێکی تر تەنها بە گۆڕینی ID ببینێت.
• Rate Limiting & SSRF: تێپەڕاندنی سنوورداریی ژمارەی داواکارییەکان و بەکارهێنانی Server-Side Request Forgery بۆ هێرشکردنە سەر سێرڤەری ناوخۆیی (Internal Network).
• JWT Token Exploitation: شیکاری Tokenەکان، تاقیکردنەوەی هێرشی None-Algorithm و لێدانی هەڵەی Signatures.

🔐 3. کریپتۆگرافی و کۆدسازی کرداری (Applied Cryptography & Hash Breaking)

تێگەیشتن لە چۆنیەتی پاراستنی داتا و هەڵە کوشندەکانی جێبەجێکردنی رەمزسازی:
• Symmetric vs Asymmetric Encryption: جیاوازی نێوان AES-256 و RSA و چۆنیەتی ڕوودانی کەلێن کاتێک IV (Initialization Vector) دووبارە بەکاردێتەوە.
• Hash Cracking with Hashcat/John: شکستپێهێنانی هاشەکان (MD5, SHA1, NTLM) بە بەکارهێنانی هێزی کارت گرافیک (GPU Accelerated Cracking) و Rule-based Attacks.
• Zero-Knowledge Proofs & Quantum Threat: ئاشنابوون بە داهاتووی رەمزسازی بەرامبەر کۆمپیوتەری کوانتۆم.

🐧 4. لینوکس بۆ هاکینگی پیشەگەر (Linux Kernel, Forensics & Hardening)

لینوکس بەردی بناغەی ئاسایشی سایبەره؛ کۆنترۆڵکردنی تەواوەتی سیستەمەکەیە:
• SUID Binary Exploitation: دۆزینەوەی فۆڵدەر و فایلی تایبەت بە مۆڵەتی Root کە هاکەر بەکاریدێنێت بۆ دەستکەوتنی باڵادەستی تەواو over Linux.
• Kernel Exploits: تێگەیشتن لە کەلێنەکانی وەک Dirty COW یان Stack Rot و ڕێگاکانی داپۆشینیان لە ڕێگەی Kernel Patching.
• Log Analysis & Auditd: ڕێکخستنی سیستەمی auditd بۆ لێکۆڵینەوە لە تێکڕای جوڵە و شیکارکردنی /var/log/auth.log کاتێک هێرش ڕوودەدات.

🕵️‍♂️ 5. لێکۆڵینەوەی ڕووداوەکان و شوێنپێی دیجیتاڵی (DFIR - Digital Forensics)

دۆزینەوەی ڕاستییەکان پاش ڕوودانی هێرش و دەستکەوتنی بەڵگەنامە دیجیتاڵییەکان:
• Memory Forensics (Volatility): دەستکەوتنی RAM Dump ی سیستەمەکە و derating فایلی شاراوە، پرۆسەی گومانلێکراو، و نێتۆرک کۆنێکشنەکانی ناو بیرگە.
• Registry & Prefetch Analysis: لە ویندۆزدا، دیاریکردنی کات و مێژووی دقیق بۆ کارکردنی فایلی تێکدەر لەڕێگەی Prefetch و Registry Artifacts.
• Chain of Custody: کۆکردنەوەی بەڵگەی یاسایی بۆ دادگا بەبێ دەستکاری بوونی Hashی ڕەسەنی هاردی زیانلێکەوتوو.

🌪️ 6. بەرەنگاربوونەوەی هێرشەکانی پەکخستنی خزمەتگوزاری (DDoS & Anti-Mitigation)

شیکاریی لافاوی داتا و ڕێگریکردن لە لەکارکەوتنی ڕێکخراوەکان:
• L3/L4 vs L7 Attacks: جیاوازی هێرشی SYN Flood, UDP Reflection لەگەڵ هێرشی خێرا و ئاڵۆزی HTTP Flood لەسەر شێوازی سەردانیکەران.
• Botnet Infrastructure: چۆن ملیۆنان ئامێری IoT (کامێرا، ڕاوتەر) دەکرێنە کۆیلە و بەکاردێن لە هێرشەکانی Mirai Botnet.
• BGP Anycast & Web Application Firewall: داڕشتنی سیستەمی بەرگری بە بەکارهێنانی Cloudflare و Rate Limiting Rules بۆ گەڕاندنەوەی ترافیکی خراپ.

⛓️ 7. ئاسایشی بلۆکچێن و گرێبەستە زیرەکەکان (Blockchain & Smart Contract Auditing)

دۆزینەوەی کەلێن لە جیهانی دراوە دیجیتاڵییەکان و تۆڕە ناوسەنتەرییەکان:
• Reentrancy Attacks: دۆزینەوەی هەڵە لە کۆدی Solidity کاتێک بەکارهێنەر بەرپەرچی هەڵگرتنەوەی پارە دەداتەوە پێش ئەوەی Balanceی نوێ بێتەوە.
• Flash Loan Exploits: چۆن هاکەران بەبێ بەرهەمهێنانی ڕاستەقینە، بە ملیۆنان دۆلار لە ئامرازی DeFi دەدزن لە ڕێگەی دەستکاری نەختینەی مارکێت.
• Cold Storage & Seed Security: ڕێگاکانی پاراستنی Private Key بەرامبەر هۆکاری دزەکردنی وێب ٣ و Clipboard Hijackers.

🎭 8. تەکنیکەکانی خۆشاردنەوە لە ئەنتی ڤایرۆس (AV/EDR Evasion & Obfuscation)

تێگەیشتن لە چۆنیەتی کارکردنی پارێزەرانی سیستەم و شوێنکەوتنیان:
• Shellcode Encryption & Injection: پەنهانکردنی کۆدی سەرەکی لە ناو بایتەکانی تر بە AES یان XOR و شاردنەوە لە ناو پرۆسەی ڕاستەقینەی ویندۆز (Process Hollowing).
• AMSI & ETW Bypass: لەکارخستنی Antimalware Scan Interface و Event Tracing for Windows لە بیرگەدا بۆ شاردنەوەی پەیپڵاینی PowerShell یان C#.
• Heuristic & Behavior Monitoring: چۆن EDR بەپێی ڕەفتار (Behavior) هێرشکار دەناسێتەوە و ڕێگاکانی API Unhooking بۆ ڕێگریکردن.

💾 9. پلانی رزگارکردن و پشتیوانی داتا (Ransomware Resilience & Backup)

دڵنیابوونەوە لە بەردەوامی کارکردنی کۆمپانیایەکی گەورە لە کاتی کارەساتی دیجیتاڵیدا:
• The 3-2-1-1-0 Backup Rule: دروستکردنی ٣ کۆپی لە داتا، لەسەر ئیلیکترۆنی جیاواز، ١ دانە لانی کەم لە دەرەوە (Offsite) و ١ دانەی بە تەواوی ئۆفلاین (Immutable Backup).
• VSS & Shadow Copies Protection: ڕێگریکردن لە ڕانسۆمۆێر بۆ سڕینەوەی Volume Shadow Copies لە ڕێگەی فرمانەکانی vssadmin.
• Disaster Recovery Testing: ئەنجامدانی سیمولەیشنی گەڕاندنەوەی سێرڤەرە سەرەکییەکان لە کەمتر لە ٣٠ خولەکدا کاتێک ڕووداوێکی هاکینگی سەخت ڕوودەدات.

⚖️ 10. پێوەر و ستانداردە جیهانییەکانی ئاسایشی زانیاری (ISO 27001 & Compliance)

داڕشتنی سیاسەتی ئەمنی بەپێی یاسا نێودەوڵەتییەکان بۆ پاراستنی کۆمپانیاکان:
• ISO/IEC 27001:2022 Controls: تێگەیشتن لە چۆنیەتی دروستکردنی ISMS (Information Security Management System) بۆ دامەزراوەکان.
• SOC 2 & GDPR Compliance: سزادانی یاسایی و یاساکانی پاراستنی تایبەتمەندیی هاووڵاتیان و پاراستنی زانیارییە داراییەکان (PCI-DSS).
• Penetration Testing Frameworks: جێبەجێکردنی هێرشەکان بەپێی ستانداردەکانی PTES و NIST SP 800-115 بۆ بەدەستهێنانی ڕاپۆرتی ڕەسمی ئەمنی.
